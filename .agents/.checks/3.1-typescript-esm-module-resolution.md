## Checks

### S1 - Resolução de módulos alinhada ao pipeline real · 7 files · 8.7 KB · ~2.2k

**C1** - Com `tsconfig.json` em `NodeNext`/`NodeNext` e imports relativos de `src/**/*.ts` ainda sem extensão, `pnpm run build` falha com erro de tipo TS2835 ("relative import paths need explicit file extensions")
Proof: `pnpm run build` (executado com `tsconfig.json` já atualizado para NodeNext, antes de qualquer import ser corrigido) — exit code `1`, saída do `tsc` contém `TS2835`

**C2** - Depois que todo import relativo em `src/**/*.ts` recebe extensão `.js` explícita, `pnpm run build` completa com exit code `0` e zero erros do `tsc`
Proof: `pnpm run build` — exit code `0`, sem linhas de erro na saída

**C3** - `node ./dist/index.js`, rodado logo após um build que satisfaz C2, não lança `ERR_MODULE_NOT_FOUND` nem `ERR_UNSUPPORTED_DIR_IMPORT` antes do primeiro ponto em que tenta se conectar a uma dependência externa
Proof: `pnpm run build && node ./dist/index.js` — processo chega ao ponto de tentar conectar ao banco (ou além) sem lançar `ERR_MODULE_NOT_FOUND`/`ERR_UNSUPPORTED_DIR_IMPORT`

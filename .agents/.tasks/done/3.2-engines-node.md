# 3.2 — Adicionar engines.node ao package.json

## Intent

Hoje, `package.json` não declara `engines`, apesar de `.nvmrc:1` fixar a versão do Node em `24`. Nada no fluxo de instalação (`pnpm install`) ou execução avisa ou impede o uso de uma versão de Node incompatível — a única fonte de verdade hoje é um arquivo que só é lido por quem usa `nvm`/`fnm` manualmente.

Depois desta mudança, `package.json` declara `engines.node` alinhado ao `.nvmrc`, tornando a versão mínima exigida legível por `pnpm`, editores e CI sem depender de um passo manual.

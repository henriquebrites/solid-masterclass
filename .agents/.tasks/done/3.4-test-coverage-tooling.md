## Intent

Hoje não existe nenhuma ferramenta de cobertura de teste instalada ou configurada: sem `@vitest/coverage-v8` (ou equivalente) em `devDependencies`, sem bloco `coverage` em `vitest.config.ts:5-6`, sem script dedicado, sem step de CI. Não há nenhuma visibilidade quantitativa sobre quais partes do código têm ou não teste — a única forma de saber hoje é inspecionar manualmente quais arquivos têm um `.test.ts` ao lado.

Depois desta mudança, `pnpm run test:coverage` produz um relatório de cobertura reproduzível (terminal + arquivo em `coverage/`), usando o provider `v8` do Vitest.

3 criteria in 1 slice · 0 one-way doors · 1 open, of which 0 block

## Criteria

1. Quando `package.json` é inspecionado, então `@vitest/coverage-v8` está presente em `devDependencies`, em versão compatível com `vitest@^5.0.1`.
2. Quando `pnpm run test:coverage` roda, então ele conclui com exit code `0` sobre a suíte atual (que já passa) e imprime um resumo de cobertura em texto no terminal.
3. Quando `pnpm run test:coverage` roda, então ele grava um artefato de cobertura legível por máquina (ex. `lcov.info` ou relatório html) em `coverage/`.
